# Yavo 诊断码与 panic 类别（草案 v0.5）

本表由测试包提出，随 P1 一起冻结。编译器的 JSON 诊断用 `code` 字段报告这些码；测试用 `//~ ERROR <码>` 标注预期位置。

## panic 类别

运行时 panic 时，进程以非零状态退出，并在 stderr 输出一行可供机器读取的记录：`yavo panic [<类别>] at <文件>:<行>:<列>: <说明>`。

| 类别 | 含义 |
| --- | --- |
| P-OVERFLOW | 加、减、乘、取负溢出 |
| P-DIV-ZERO | 除以 0，或对 0 取余 |
| P-DIV-OVERFLOW | 最小整数除以 -1，或对 -1 取余 |
| P-SHIFT | 移位量为负，或不小于位宽 |
| P-CONVERT | 整数窄化或负数转无符号超出范围 |
| P-FLOAT-CONVERT | 浮点转整数时遇到 NaN、无穷或超出范围 |
| P-INDEX | 下标越界 |
| P-STR-BOUNDARY | 子串两端没有落在字符边界上 |
| P-ARENA-ID | Id 属于另一个 Arena |
| P-OOM | 分配器无法满足已验证为合法大小的分配 |
| P-CAPACITY | 容量为负、元素数乘大小或地址跨度超界 |
| P-COMPARATOR | 检测到比较协议违反 |
| P-LOCK-REENTRANT | 同线程重复获取非递归锁 |
| P-SYSTEM | 内建系统操作出现不可恢复错误 |
| P-THREAD-SPAWN | 无法创建 OS 线程 |
| P-CHANNEL-CAP | channel 容量不为正数 |

## 启动错误

非法编码的命令行参数使用 `YAVO-STARTUP-UTF8`，在 main 之前报出并非零退出。这不是 Yavo 栈中某个表达式的 panic。

## 诊断优先级

同一根因只产生一个主诊断，其余位置作为 secondary。优先级按具体上下文：Map 键写入用 E0103；通过只读权限写入用 E0101；有效类型上的别名冲突用 E0102；无两阶段借用的接收者/实参冲突用 E0403；直接移出已有字段/模式借用用 E0401；在拥有类型上下文尝试隐式读取非 Copy 值用 E0404。类型或签名已无效的子树使用错误占位，抑制由它引起的级联主错误。测试要求主诊断码和行一致，不要求相关说明只能出现一处。
