# Yavo 诊断码与 panic 类别（草案 v0.4）

本表由测试包提出，随 P1 一起冻结。编译器的 JSON 诊断用 `code` 字段报告这些码；测试用 `//~ ERROR <码>` 标注预期位置。

## 编译错误

| 码 | 含义 | 语义表规则 |
| --- | --- | --- |
| E0001 | 类型不匹配（包括没有隐式转换的地方） | 第 8 节 |
| E0101 | 通过只读借用写入 | A1、A2 |
| E0102 | 同一位置的借用冲突（两个可变借用，或可变借用与其他访问重叠） | A3、A4 |
| E0103 | 修改 `Map` 的键 | A5 |
| E0301 | 携带借用的值进入普通字段、`Box`、接口值或泛型包装 | C1、C3、E1、E2 |
| E0302 | 返回值携带借用，但签名没写 `of` | O1 |
| E0303 | 返回值的来源超出 `of` 的声明 | O2 |
| E0304 | `of` 指向 `sink` 参数或局部变量 | O2 |
| E0305 | 借用活得比来源长 | E4、O1 |
| E0306 | 通过 `inout` 参数写入来自其他输入的借用 | O4 |
| E0307 | 会被保存的闭包捕获了借用 | O5 |
| E0401 | 从借用的位置移出值 | C5、速查卡规则 8 |
| E0402 | 使用已移动的值（包括已移动的 `&inout`） | 第 2 节、V1 |
| E0403 | 接收者已被借用时，实参又访问同一位置（v1 不做两阶段借用） | V2 |
| E0404 | 不可复制的值不能从借用里隐式取得 | C4 |
| E0501 | 类型不满足 `Eq` 或 `Ord` | K1 |
| E0601 | 块形式的 `catch` 能正常走到结束花括号 | V8 |
| E0701 | 类型不满足 `Send` | P1、P2、P6 |
| E0702 | 类型不满足 `Sync` | P2 |
| E0703 | 锁守卫内借出的引用离开了 `with` 块 | P4 |
| E0704 | channel 的元素类型携带借用 | P5 |
| E0705 | 线程借用的数据活得不够久 | P3 |

## 警告

| 码 | 含义 | 修复级别 |
| --- | --- | --- |
| W0001 | 未使用的变量 | 一级：改名为 `_name` |

## panic 类别

运行时 panic 时，进程以非零状态退出，并在 stderr 输出一行可供机器读取的记录：`yavo panic [<类别>] at <文件>:<行>:<列>: <说明>`。

| 类别 | 含义 |
| --- | --- |
| P-OVERFLOW | 加、减、乘、取负溢出 |
| P-DIV-ZERO | 除以 0，或对 0 取余 |
| P-DIV-OVERFLOW | 最小整数除以 -1，或对 -1 取余 |
| P-SHIFT | 移位量为负，或不小于位宽 |
| P-CONVERT | 整数窄化或负数转无符号超出范围 |
| P-FLOAT-CONVERT | 浮点转整数时遇到 NaN、无穷或超出范围 |
| P-INDEX | 下标越界 |
| P-STR-BOUNDARY | 子串两端没有落在字符边界上 |
| P-ARENA-ID | Id 属于另一个 Arena |
| P-OOM | 内存耗尽，或容量计算溢出 |
