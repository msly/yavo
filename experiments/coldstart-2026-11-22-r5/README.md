# 第五轮：两语言各 24/24 首稿正确，Yavo 用时仍为 Rust 的 1.205 倍

**Yavo、Rust 各运行两个独立会话，每个会话完成 12 道新规格任务；48 份交付全部首编成功，首稿通过全部公开、隐藏用例和必需的模块/线程结构审查。没有编译失败、源码修复或首稿到终稿的修改。** Yavo 合计 138 次受控操作、671.29 秒，Rust 为 132 次、557.04 秒。正确性在本题包上打平；本轮未建立效率优势。

原始判定与统计见 [results.json](results.json)、[成本分解](evidence/cost-analysis.json)、[行为复核](evidence/behavior-review.json)和[结构审查](evidence/manual-review.json)。完整 token 成本仍缺失：当前协作接口不提供可核验 usage，CLI 在模型请求前因只读文件系统初始化失败；token、精确服务模型 ID、采样参数均保留 `null`，不作估算。执行器探针保存在 [executor-probe.json](evidence/executor-probe.json)。

## 题目与边界

完整规格及公开样例见 [TASKS.md](TASKS.md)，参考算法和冻结隐藏用例在 [judge/](judge/)。每题隐藏部分包含八个明确边界和四个固定种子随机输入；题包在首位受试启动前生成、复核并冻结。

| 题 | 新规格 | 主要检查 |
| --- | --- | --- |
| T01 | 原子转账账本 | 批次回滚、自转账、余额超过输入初值上限 |
| T02 | 严格 CSV 单行解析 | 引号、双引号转义、空字段、非法行 |
| T03 | 整数区间集合增删 | 相邻区间合并、删除拆分、空集合 |
| T04 | 精确长度换算 | 前导零、负零、分数约分、非法格式、真实模块分工 |
| T05 | 网格连通域标号 | 四邻接、孔洞周长、确定编号和面积 |
| T06 | 三线程游程编码 | 空分片、三个线程全部先启动、跨分片边界合并 |
| T07 | TTL＋LRU 缓存 | 到期边界、零容量、TTL=0、get 不延期、同时间顺序 |
| T08 | 标签目录查询 | 去重、交集、替换与确定输出 |
| T09 | 带转义的 glob | 全串匹配、转义、连续通配符及空文本 |
| T10 | 相对路径归一化 | `.`、`..`、重复分隔符、根越界处理 |
| T11 | 滑动窗口下中位数 | 偶数窗口、重复值、负数与短序列 |
| T12 | 版本号稳定排序 | 大数字 PRE、前导零、BUILD 不参与排序、稳定等价项 |

这十二份规格没有复用第三、四轮题包；T01、T06、T07 分别在更早轮次的账户、游程编码、LRU 题型上加入新的规则或组合，不能称为十二种全新题型或严格题型留出。第四轮受试者记载为 Sonnet，本轮继承当前 ChatGPT 父级配置；模型与题目同时变化，不把跨轮差异归因于某一项语言修改。

## 后续工程取舍

本题包没有产生新的语法、借用、库缺口或编译器行为反例，不据此追加语言语义变更。下一步的 Agent 优化实验优先解决两件事：

1. 接入能返回真实 usage、精确模型标识和可保存执行转录的运行器，补齐 token 与单位成功交付成本。当前证据不能验收“比 Rust 低 20%”的正式成本门。
2. 将现有 513 行速查卡拆成最小编写说明和按需 API 文档，用新任务作对照。检验缩短初始输入后能否保持首次正确率，并分别记录文档输入、生成输出与等待时间；本轮不能单靠 6 次文档请求判断全部时间差来自文档。

之后按既定计划进入 60 题 pilot，再依据方差设计起点不少于 400 题的正式实验。12 题诊断不代替完整 v1、Agent 正式成本门或 C 性能门。
