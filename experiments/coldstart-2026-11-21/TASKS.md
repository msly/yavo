# 任务 T01–T12

每题写一个命令行程序。没有特别说明时：标准输出要与 `tasks/TNN.out` 逐字节相同，标准错误必须为空，退出码为 0。
“行”不含换行符；输入以换行结尾。输出每行以换行结尾。字段以空白（空格或制表符）分隔，多个空白算一个分隔。
单文件题的程序放在 `TNN.<扩展名>`；T04、T05 是多文件题，放在目录 `TNN/` 里，入口文件是 `TNN/main.<扩展名>`。

## T01 好友网络
运行：`T01 < tasks/T01.in`
每行一条命令，空行跳过：
- `add NAME`：新建用户。
- `link A B`：A 与 B 成为好友（无向）；已经是好友则什么都不做。
- `unlink A B`：解除好友关系。
- `remove NAME`：删除用户及其全部好友关系。之后可以再 `add` 同名的新用户，新用户没有任何好友。
- `path A B`：输出 A 到 B 的最短好友链 `path: A -> X -> B`（A 与 B 相同时输出 `path: A`）；不连通输出 `path: none`。
  用广度优先搜索：从 A 出发，每个用户的好友按名字字节序依次扩展，输出第一次到达 B 时的那条链。
- `friends NAME`：`NAME: 好友1 好友2 …`（按名字字节序）；没有好友输出 `NAME: (none)`。
成功的 add/link/unlink/remove 没有输出。错误输出一行后继续处理下一行，检查顺序：
1. 命令名未知或字段个数不对：`error: bad command`
2. 引用的用户不存在（按参数顺序检查）：`error: no user X`；`add` 的用户已存在：`error: NAME exists`
3. `link A A`：`error: self link`；`unlink` 的两人不是好友（包括 A 与 B 相同）：`error: not linked`
最后输出 `users: N links: M`（当前用户数、好友关系数）。

## T02 文本缓冲区
运行：`T02 < tasks/T02.in`
第 1 行是初始文本（可能为空），光标在文本末尾。之后每行一条命令（n 是正整数）：
- `L n` / `R n`：光标左移 / 右移 n 个字符，到头为止。
- `I text`：在光标处插入 text（命令后第一个空格之后的全部内容，非空，可以含空格），光标移到插入内容之后。
- `D n`：删除光标后的 n 个字符（不够就删到末尾）。`B n`：删除光标前的 n 个字符（不够就删到开头），光标随之左移。
- `P`：输出当前文本，在光标处插入一个 `|`。
- `U`：撤销最近一次尚未撤销的 I、D 或 B（即使它实际删除了 0 个字符），文本和光标都恢复到那条命令之前的状态；可以连续撤销多次；没有可撤销的命令时输出 `nothing to undo`。L、R 不会被撤销，也不算一条可撤销的命令。
其他任何行（包括空行）输出 `bad command at line K`（K 从 1 开始计，初始文本是第 1 行），然后继续。
最后输出 `final: 文本` 和 `length: 字符数`。文本只含可打印 ASCII 字符。

## T03 表达式
运行：`T03 < tasks/T03.in`
每行一个整数表达式：十进制非负整数（不含前导零）、`+ - * / %`、括号、一元负号、任意空格。语法（左结合）：
```
expr  := term (('+' | '-') term)*
term  := unary (('*' | '/' | '%') unary)*
unary := '-' unary | primary
primary := NUMBER | '(' expr ')'
```
- 解析成功：输出完全加括号的形式、` = `、值。二元运算写成 `(左 op 右)`，一元负号写成 `(-x)`，数字原样。例：`1+2*-3` → `(1 + (2 * (-3))) = -5`。
- `/` 向零取整，`%` 的结果与被除数同号。先完整计算左操作数再计算右操作数；遇到第一个除数为 0（`/` 或 `%`）时，值的位置输出 `error: division by zero`，例：`(1 / 0) = error: division by zero`。
- 解析失败：遇到不该出现的记号输出 `error at col C: unexpected 'X'`，C 是该记号第一个字符的列号（从 1 开始），X 是该记号的全部文本（数字记号是整个数字，其他是单个字符）；表达式没写完就到行尾输出 `error: unexpected end`（空行或全是空格的行也是）。表达式完整解析后若还有剩余记号，按“不该出现的记号”报告。
测试中的数和中间结果都在 64 位有符号整数范围内。

## T04 配置文件（多文件）
运行：`T04 server.port db.url name db.dsn loop.a db.missing nosuch.key bad.ref < tasks/T04.in`，期望 `tasks/T04.out`；
`T04 x < tasks/T04bad.in`：无标准输出，标准错误为 `tasks/T04bad.err`，退出码 2。
代码要求：至少两个源文件。全部解析和展开逻辑放在入口文件以外的文件里；入口文件只负责读输入、取参数和输出。
输入的每一行先去掉首尾空白，然后：
- 空行，或以 `#`、`;` 开头：忽略。
- `[NAME]`：开始一个节，NAME 是方括号之间的内容去掉首尾空白，必须非空。之后的键都属于这个节。同名的节可以出现多次，内容合并。
- 含有 `=`：键是第一个 `=` 之前的部分去掉首尾空白（必须非空），值是之后的部分去掉首尾空白（可以为空）。在任何节之前出现的键属于“全局节”。同一节里重复的键以后出现的为准。
- 其他行都是语法错误：标准错误输出 `line N: syntax error`（N 是第一个出错的行号，从 1 开始），退出码 2，没有标准输出。
节名和键都不含 `.`。查询 `S.K` 指节 S 的键 K（按第一个 `.` 分开）；不含 `.` 的查询指全局节的键。
值里的 `${REF}` 引用另一个键（REF 的写法与查询相同），输出时递归展开；`${` 之后没有 `}` 时原样保留。对每个命令行参数 Q 输出一行：
- Q 不存在：`Q: not found`
- 展开时从左到右、深度优先，遇到不存在的引用 R：`Q: missing R`；遇到一个正在展开中的键（环）：`Q: cycle`。两者以先遇到的为准。
- 否则：`Q = 展开后的值`

## T06 并行统计

## T07 作业调度
运行：`T07 < tasks/T07.in`，标准错误要与 `tasks/T07.err` 相同。
每行 `NAME ARRIVAL DURATION PRIORITY`：到达时间、优先级是非负整数，时长是正整数。字段个数不对或数值不合法的行向标准错误输出 `line N: invalid` 并忽略。名字互不相同。
单个处理器从时刻 0 开始，非抢占：处理器空闲时，在已到达（到达时间 ≤ 当前时刻）的作业中选优先级最大的，相同则到达早的，再相同则名字字节序小的，一直运行到结束；没有已到达的作业就空闲到下一个作业到达。
每个作业开始时输出 `t=开始时刻 NAME (waited 等待时间)`（等待时间 = 开始时刻 − 到达时间）。最后输出 `avg wait: X.XX`（平均等待，两位小数；没有作业时为 0.00）、`idle: N`（从 0 到最后一个作业结束之间的空闲总时长）和 `end: T`（最后结束时刻，没有作业时为 0）。

## T09 文件系统
运行：`T09 < tasks/T09.in`
维护一棵目录树，开始只有根目录 `/`。路径都以 `/` 开头，各级以单个 `/` 分隔，除根以外不以 `/` 结尾。每行一条命令，空行跳过：
- `mkdir P`：创建 P 及缺少的上级目录；P 已是目录则什么都不做；途中某一级是文件：`error: not a directory X`（X 是该文件的路径）。
- `touch P SIZE`：创建或覆盖大小为 SIZE（非负整数）的文件。上级目录不存在或不是目录：`error: no such directory 上级路径`；P 是目录：`error: is a directory P`。
- `rm P`：递归删除。P 不存在：`error: no such path P`；P 是 `/`：`error: cannot remove root`。
- `mv S D`：S 不存在：`error: no such path S`；S 是 `/`：`error: cannot move root`。若 D 是已存在的目录，目标为 `D/S的名字`；若 D 是已存在的文件：`error: exists D`；
  若 D 不存在，D 的上级必须是已存在的目录（否则 `error: no such directory 上级路径`），目标为 D（即改名）。目标等于 S 或位于 S 之内：`error: cannot move into itself`；目标已存在：`error: exists 目标路径`。
- `du P`：输出 `P 大小`（文件是自身大小，目录是其中所有文件之和）。P 不存在：`error: no such path P`。
- `ls P`：P 是目录时输出 `P: 子项1 子项2 …`（按名字字节序，目录名后加 `/`），空目录输出 `P: (empty)`；P 是文件时输出 `P`；不存在：`error: no such path P`。
命令名未知、字段个数不对或 SIZE 不合法：`error: bad command`。错误输出一行后继续。
最后输出整棵树：第一行 `/ 总大小`；然后深度优先列出每个目录的内容，每深一级多缩进两个空格（根的直接子项缩进两个空格）；同一目录下的子项按名字字节序排序，目录写成 `名字/ 目录大小`，文件写成 `名字 大小`。

## T10 动态分发
运行：`T10 < tasks/T10.in`
代码要求：用 3 个工作线程。任务（每行一个）动态分配：哪个工作线程空闲就领取下一个尚未处理的行，不能事先把行均分给线程。输出顺序与输入顺序一致。
每行若是 1 到 10^7 之间的十进制整数 N，输出 `N: steps=S peak=P`：从 N 开始反复变换（偶数除以 2，奇数变为 3N+1）直到 1，S 是变换次数，P 是途中出现的最大值（包括 N 本身）。
否则（包括空行）输出 `line K: invalid`（K 从 1 开始）。最后输出 `longest: N (S steps)`，S 最大者，相同取最先出现的；没有有效行时输出 `longest: none`。

## T11 行差异
运行三次：
- `T11 tasks/T11a.txt tasks/T11b.txt`：期望 `tasks/T11ab.out`，退出码 1；
- `T11 tasks/T11a.txt tasks/T11a.txt`：期望 `tasks/T11aa.out`，退出码 0；
- `T11 tasks/nosuch.txt tasks/T11a.txt`：无标准输出，标准错误为 `error: cannot read tasks/nosuch.txt`，退出码 2。
读入两个文件的行 a[0..n)、b[0..m)。设 L[i][j] 为 a[i..] 与 b[j..] 的最长公共子序列长度。从 i = 0、j = 0 开始：
当 i < n 且 j < m 时，若 a[i] == b[j]，输出 `  a[i]`（两个空格），i、j 都加 1；否则若 L[i+1][j] >= L[i][j+1]，输出 `- a[i]`，i 加 1；否则输出 `+ b[j]`，j 加 1。
之后把剩余的 a 依次输出为 `- 行`，剩余的 b 输出为 `+ 行`。最后输出 `summary: -删除行数 +增加行数`。两文件相同时退出码 0，否则 1。

## T12 哈夫曼编码
运行：`T12 < tasks/T12.in`
统计标准输入中每个字节的出现次数。每个出现过的字节是一个结点，键为（次数，字节值）。反复取出键最小的两个结点 x、y（x 更小），合并成新结点：左孩子 x、右孩子 y，键为（x 次数 + y 次数，x 和 y 子树中最小的字节值）；直到只剩一个结点。
从根出发，向左记 `0`、向右记 `1`，到叶子的路径是该字节的编码；只有一种字节时它的编码是 `0`。
按字节值从小到大，对每个出现过的字节输出 `字节 次数 编码`，其中字节值 33–126 写成该字符本身，其他写成 `\xHH`（两位大写十六进制，如换行是 `\x0A`、空格是 `\x20`）。
然后输出 `bits: 编码总位数` 和 `depth: 最长编码的长度`。输入为空时只输出 `bits: 0`。
