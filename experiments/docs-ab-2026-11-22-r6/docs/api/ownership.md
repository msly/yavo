## 4. 所有权：九条规则

没有 GC，也没有生命周期标注。写代码时记住下面九条；完整规则和边界情况见语义表。

1. **移动与复制。** 按值赋值、放进集合、传给 `sink` 参数时，拥有值（`String`、`Vec`、`Box` 等）被移动，之后原变量不能再用。标量及无析构、有效载荷递归满足 Copy 的类型自动复制；`str`、`&T` 复制的只是描述符；`&inout T` 不能复制。要第二份拥有值时写 `.clone()`。
2. **参数默认是只读借用。** 要修改调用者的值，参数写 `inout`，调用处写 `&x`；要拿走所有权，参数写 `sink`。
3. **权限看借用类型，不看 `var`。** `let`/`var` 只管能否重新赋值；`&T` 只读，`&inout T` 可写；把 `&T` 放进 `var` 也不能写。`if let`、`match` 对已有位置继承访问权限。`for` 默认只读；写 `for k, v in &m` 才取得 `&inout V`，循环体此时不能再直接访问 `m`。`Map` 键永远只读。标量借用通过 `*p = value` 写入。
4. **视图不能逃逸。** 视图（`str`、`[]T`、`&T`、`&inout T`）和携带视图的值（如 `Vec[str]`）可以做局部变量、参数和返回值，不能进入普通字段、`Box`、接口值、channel 或被保存的闭包。`.toVec()` 不会消除元素里的借用；要长期保存，逐个 `.toString()`，或者只存下标区间。v1 没有可变切片。
5. **每个具名函数返回借用时都写来源**，私有函数和泛型函数也一样：`-> str of s`、`-> str of (a, b)`、`-> str of self`、`-> str of static`、`-> ?T of xs`。`of` 只能指向借用参数：`fn bad(text: sink String) -> str of text` 会被拒绝，因为 `text` 在函数结束时就被释放了。
6. **不能通过参数写入新借用。** 函数不能把来自其他参数的借用写进 `inout` 参数（如 `out: inout Vec[str]`），要改为返回 `Vec[str] of text`。
7. **借用持续到最后一次使用；实参从左到右，每个立即完成移动或借用。** 修改接收者的调用（`v.push(x)`、`m.set(k, v)`、`inout self` 方法）和 `v[i] = x` 里，实参可以**读**接收者：`v.push(v.len())`、`v.push(v[i] + v[j])`、`dp[i] = dp[i - 1] + dp[i - 2]`、`c.add(c.n)` 都合法；但实参不能**修改或移动**接收者（`v.push(v.pop() ?? 0)` 报 `E0403`），实参的值也不能还指着它（`t.push(t)` 报 `E0403`）——这种情况先 `let x = …` 算好再调用。元素也可以做修改方法的接收者：`groups[i].push(x)`、`ms[i].set(k, v)`、`ps[i].tags.push(s)`、`ps[i].moveBy(1)`；这时先定位元素（求下标、检查越界）并可变借用它，再求实参，所以实参不能再用这个容器（`groups[i].push(groups.len())` 报 `E0403`，先 `let n = groups.len()`）。**读出非 Copy 的元素是借用**：`let t = v[i]`（元素是 `String`、`Vec` 等）得到 `&T`，之后只要还会用 `t`，就不能修改 `v`（`E0102`）；要独立的值写 `let t = v[i].clone()`。（字段不同：`let q = s.name` 是移出，按规则 8 报错。）
8. **不允许部分移动。** 非 Copy 字段、`Box` 内容或集合元素都不能直接移出，即使外层由本函数拥有。 有默认值的类型用 `take(&x)` 取走并留下默认值（可选值留下 `none`，数字留下 0，`String`、`Vec`、`Map` 留下空值）；其他类型用 `replace(&x, 新值)` 或 `swap(&a, &b)`。例外：匹配拥有的临时值（如 `match ch.recv()`）可以移出其中的值；要消费已有的可选变量，写 `match take(&opt)`。
9. **结构的选择。** 递归结构用 `?Box[T]`；单线程共享用 `Rc[T]`；跨线程共享用 `Arc[T]`，条件见第 6 节；互相引用的图用 `Arena[T]` 加 `Id[T]`。

```
struct Node {
    key: int
    left: ?Box[Node]
    right: ?Box[Node]
}

fn insert(t: inout ?Box[Node], k: int) {
    if let n = t {                        // 规则 3：t 是 inout，n 可写
        if k < n.key {
            insert(&n.left, k)            // 规则 2：再借用子字段，调用处写 &
        } else if k > n.key {
            insert(&n.right, k)
        }
        return
    }
    t = Box(Node{key: k})                 // 未写的可选字段默认是 none
}

fn removeRoot(t: inout ?Box[Node]) {      // 假设根最多只有一个孩子
    var child: ?Box[Node] = none
    if let n = t {
        if n.left.isSome() {
            child = take(&n.left)         // 规则 8：取走子树，原处留下 none
        } else {
            child = take(&n.right)
        }
    }                                     // n 的最后一次使用已过，借用结束
    t = child
}

fn firstWord(s: str) -> str of s {        // 规则 5：私有函数也写来源
    return s.fields()[0]                  // 复制出的 str 指向 s，不指向临时的 Vec
}

fn words(text: str) -> Vec[str] of text { // 规则 4、6：返回带来源的视图集合，不复制字符串
    var out: Vec[str] = []
    for w in text.fields() {
        out.push(w)                       // 局部容器可以写入借用
    }
    return out
}

fn countWords(text: str) -> int {
    let ws = words(text)
    let n = ws.len()                      // 规则 7：先算出来，再作为实参
    return n
}

struct Doc {
    words: Vec[String]                    // 规则 4：字段里存 String，不存 str
}
```

图结构的写法：节点放在 `Arena[T]` 里，用 `Id[T]` 互相指向；读取返回借用。

```
struct Person {
    name: String
    friends: Vec[Id[Person]]
}

fn main() {
    var people = Arena[Person]{}
    let a = people.add(Person{name: "Ann".toString(), friends: []})
    let b = people.add(Person{name: "Bo".toString(), friends: [a]})
    if let p = people.getMut(a) {         // p 是 &inout Person
        p.friends.push(b)                 // 互相引用没有问题

    }
    // 把 a 用在另一个 Arena 上会 panic：Id 里带着它所属 Arena 的身份
}
```

## 1. 访问权限

- **A1 绑定可变性与借用权限分开。** `let`/`var` 只决定绑定能否重新赋值；`&T`/`&inout T` 决定能否修改目标。把 `&T` 放进 `var` 不能获得写权限；`let` 绑定可以持有 `&inout T` 并通过它修改目标，但不能换成另一个引用。
- **A2 区分匹配和遍历。** `if let`、`match` 对已有位置的绑定沿用该访问路径的权限；来自只读路径的绑定不能升级为可写。`for x in xs` 一律只读遍历，即使 `xs` 是 `var`；要写元素，显式写 `for x in &xs`，要求可变拥有位置或有效的可变再借用。`Map` 的键两种遍历下都只读。临时拥有集合可以直接只读遍历，集合存活到循环退出；不能对临时集合写 `for x in &makeVec()`。只读切片不因其绑定为 `var` 而支持可变遍历。
- **A3 排他性。** 同一个位置在同一时刻，要么有任意多个只读借用，要么只有一个可变借用。禁止的是冲突访问，不是禁止通过可变借用本身修改目标。
- **A4 再借用。** 可以从 `&inout T` 再借出它的子字段或整体，例如 `insert(&n.left, k)`。再借用存活期间，原路径不能做冲突访问；再借用结束后，原借用恢复可用。
- **A5 Map 的键只读。** 遍历或 `getMut` 得到的键永远是 `&K`；要改键，先删除再重新插入。

- **A6 显式解引用。** `*p` 表示借用指向的位置。`*p = v`、`*p += v` 仅在 `p: &inout T` 时合法；`p = q` 改的是引用绑定本身，要求 `var p`。读 `*p` 时，`T: Copy` 得到副本，否则得到只读访问，不能把非 Copy 值搬出。`inout` 参数本身是位置别名：`fn set(x: inout int) { x = 1 }` 不必写 `*x`。
- **A7 借用构造与透明投影。** `&place` 在 `inout` 调用处或期望类型为 `&inout T` 时建立可变借用；期望类型为 `&T` 时建立只读借用。独立的 `let p = &x` 没有权限上下文，拒绝并要求写类型，如 `let p: &int = &x`。字段、方法和下标只对内建借用、`Box`、`Rc`、`Arc`、`Guard` 自动投影，不调用用户自定义解引用。投影不增加权限。普通默认参数对显式 `&inout T` 只提供只读访问；转交该排他描述符使用 `sink &inout T`，短期修改优先使用 `inout T`。
- **A8 遍历借用边界。** 整个迭代过程借用容器；只读遍历允许其他只读访问，禁止扩容、删除、替换和移动。可变遍历禁止循环体直接访问同一容器，只能使用当前元素绑定。循环退出后释放迭代借用；借用不能绕过 `continue`、嵌套循环或闭包保存而逃出当前有效范围。

```text
var n = 1
let p: &inout int = &n
*p += 1
// p 的最后一次使用之后，允许再次读取 n
println(n)
```

## 2. 复制、移动与读取

普通参数默认是只读借用，不受下表影响；下表只说明按值赋值和传给 `sink` 参数时发生什么。

| 类型 | 按值赋值或传给 `sink` 时 | 说明 |
| --- | --- | --- |
| 标量（整数、浮点、`bool`、`byte`）、`Id[T]` | 复制 |  |
| `str`、`&T`、`[]T`（v1 只有只读切片） | 复制描述符 | 不复制被引用的数据；副本携带同样的来源 |
| `&inout T` | 不可复制 | 只能移动或受检查地再借用 |
| `String`、`Vec[T]`、`Map[K, V]`、`Box[T]` 等拥有值 | 移动 | 要第二份写 `.clone()` |
| 携带借用的拥有值，如 `Vec[str]` | 移动 | 容器拥有自己的存储，元素借用外部数据；借用关系随容器移动 |
| 无用户析构、各有效载荷递归满足 Copy 的元组、可选值、结果值、结构体和枚举 | 复制 | 仍须满足字段逃逸规则；实现 Drop 或包含需析构资源的类型不为 Copy |

- **C1 携带借用。** 一个类型直接或递归地包含 `str`、`&T`、`&inout T` 或 `[]T` 时，就“携带借用”。携带借用的值服从第 4 节的逃逸限制，即使它自己拥有存储。销毁它只释放它自己的存储，不释放被引用的数据。
- **C2 `v[i]` 的含义。** 在读取上下文中：元素可复制时得到副本（`str` 元素得到描述符副本，指向原字符串，而不是容器的槽位）；元素不可复制时得到 `&T`，同时借用容器。在赋值左侧或 `&v[i]` 中得到可变位置，要求可变访问路径。v1 没有可变切片，修改元素用 `inout Vec[T]` 或元素的可变借用。
- **C3 `.toVec()` 与 `.toString()`。** `.toVec()` 只让容器拥有元素存储，元素是否携带借用取决于元素类型：`[]str` 得到的 `Vec[str]` 仍然携带借用；要完全独立，逐个转成 `Vec[String]`。`.toString()` 得到不携带借用的 `String`。
- **C4 读取可复制的值。** 期望类型是可复制的 `T`、实际是 `&T` 或 `&inout T` 时，编译器自动读取一份 `T`：复制的是被借的值，不是复制引用。普通遍历得到 `&int`，`for ... in &map` 得到 `&inout int`；两者都可在期望 `int` 的位置复制读取，`items.push((k.clone(), n))` 合法。无期望值类型的 `let q = p` 保留描述符类型；若 `p` 是可变借用则移动它，而不是自动读取目标。
- **C5 模式匹配的所有权。** 对已有位置（变量、字段、集合元素）做匹配时，按访问权限借用其中的值；对拥有的临时结果（如 `ch.recv()`、`v.pop()`、函数返回值）做匹配时，可以把其中的值移出来。要消费一个已有的可选变量，写 `match take(&opt)`。这是禁止部分移动的限定例外：对完整拥有的临时可选值、结果值、枚举或元组做解包，可以移出其有效载荷。直接从普通字段、`Box` 内容或集合元素移出非 Copy 值一律禁止，即使外层对象由当前函数唯一拥有。已有位置仍用 `take`、`replace`、`swap`，或复制/借用；不启用 Rust 式任意部分移动。实现了用户 Drop 的类型不能被模式解体。
- **C6 借用键查询。** `Map[String, V]`、`Set[String]` 的查询接受 `str`，不创建临时 `String`；插入接收拥有的键。查询形式和拥有形式的哈希与相等语义必须一致。

- **C7 可选模式和通配符。** `?T` 的构造为 `some(value)`、`none`，模式为 `some(x)`、`none`，`if let x = opt` 等价于只处理 `some(x)` 的匹配。`match` 必须穷尽。对已有位置做匹配只借用；对拥有临时值的 `some(x)` 绑定取得拥有值。临时有效载荷匹配 `_` 时在进入该分支前丢弃；匹配已有位置的 `_` 不移动或销毁原值。命名 `_x` 保留值到分支作用域结束，只抑制未使用警告。
- **C8 字段和整体移动。** `sink` 可以接收整个拥有变量；不能因此允许 `sink` 接收非 Copy 字段。`let (a, b) = pair` 对已有位置按 C5 借用，`let (a, b) = makePair()` 可消费完整临时元组。`Box` 可整个移动，但不增加直接取出其内容或字段的特殊语法。

```text
var opt: ?String = some("job".toString())
match take(&opt) {
    some(job) => consume(job)  // job 是拥有值
    none => println("empty")
}
```

## 3. 借用来源（`of`）与写入关系

- **O1 所有具名函数和方法都写来源。** 包括私有函数和接口方法；返回值携带借用时（含 `Vec[str]`、可选值、元组、结果类型里的借用），签名必须写 `of`。泛型返回类型里的类型参数可能携带借用时，也必须写来源上界；实例化后不携带借用（如 `largest[int]`），这个标注就不产生借用约束。纯拥有值的返回不写。

```
fn trimmed(text: str) -> str of text
fn choose(a: str, b: str, pickA: bool) -> str of (a, b)
fn name(self) -> str of self
fn languageName() -> str of static
fn words(text: str) -> Vec[str] of text
fn largest[T: Ord + Copy](xs: []T) -> ?T of xs
```

| 写法 | 含义 |
| --- | --- |
| `of text` | 来自参数 `text` |
| `of self` | 来自接收者 |
| `of (a, b)` | 可能来自其中一个或多个；调用方按全部列出的来源保守检查 |
| `of static` | 只指向程序全程有效的数据，例如字符串字面量、`os.args()` |

- **O2 来源是上界。** 编译器检查函数体没有超出声明；调用方只看签名，不读函数体去缩小或扩大来源。实现改了而违反声明时，错误报在函数内部。`of` 只能指向借用参数（默认参数、`inout` 参数）或借用的接收者，不能指向 `sink` 参数或局部变量：来源匹配只是必要条件，`of` 不会延长拥有者的寿命。所以 `fn bad(text: sink String) -> str of text` 会被拒绝。
- **O3 不自动补 `of`。** 缺失或写错时，编译器给出候选补丁，但不自动应用，也不自动扩大已声明的来源。
- **O4 不能通过参数引入新的外部来源。** 对普通函数的每个 `inout` 参数，退出时所携带的来源只能来自该参数进入函数时已有的来源或 `static`，不能新增其他参数或局部拥有者的来源。规则同时检查赋值、`push`、`set`、`replace`、`swap` 和回调写入，不能借内建调用绕过。需要新增来源时改为返回带 `of` 的拥有容器。局部容器允许聚合来源。内建操作有固定的前态/后态来源契约：例如 `out.push(s)` 合并来源，`get` 返回元素槽位借用，复制出的 `str` 只保留底层文本来源。来自输入的来源集合须在调用前快照，不能把后写入的来源倒灌给已返回的旧值。
- **O5 闭包。** 不逃逸的匿名闭包（立即传给 `sortBy`、`update` 等）可以借用外部变量，来源在当前函数内推断。v1 只有编译器已知 noescape 契约的标准库回调可以这样借用；没有契约的用户高阶参数按可能逃逸处理，借用捕获被拒绝，不开放临时推断出来的隐含例外。会被保存的闭包（如 `Heap.by` 的比较函数、放进字段的闭包）不能捕获任何借用，只能移动捕获拥有值。

- **O6 参数视图的描述符。** `str`、只读 `[]T` 和 `&T` 传参时复制小型描述符，来源指向实际数据，不指向调用者用于保存描述符的局部槽位。默认 `Vec[T]` 参数借用拥有容器；`Vec[T]` 到 `[]T` 的自动视图转换见第 8 节。泛型来源可以保守合并参数存储与其嵌套来源；内建 `str` 和 `[]T` 操作必须区分描述符存储与底层数据，避免临时容器销毁造成假悬空或真悬空。
- **O7 库特殊资源。** `Guard[T]`、`Join[T]` 是带编译器资源契约的内建类型，不以普通用户字段模拟。`Guard` 携带锁的来源与许可；`Join` 受所属 scope 限制。这些类型同样不能进入普通长期字段、共享盒、channel 或全局变量，除非将来增加独立且经过测试的规则。

## 4. 逃逸限制

- **E1 能去哪里。** 携带借用的值可以做局部变量、参数和带 `of` 的返回值；不能进入普通字段、`Box`、`Rc`、`Arc`、接口值、channel、全局变量或会被保存的闭包。
- **E2 递归检查。** 包在泛型结构、可选值、元组、结果类型或其他容器里同样受限：`Box[Vec[str]]`、`Wrapper[str]`、类型为 `?&T` 的字段都会被拒绝。
- **E3 证明不了就拒绝。** v1 宁可误拒：编译器无法证明不逃逸的组合一律拒绝，诊断说明原因，并给出改用拥有值的写法。
- **E4 赋给外层变量。** 把携带借用的值赋给外层作用域的变量时，来源必须活得至少和那个变量一样久。
- **E5 长期保存的办法。** `.toString()`、逐元素转成 `String`，或者只存下标区间。

## 5. 并发与资源

编译器从类型结构自动推导两种能力：`Send`（拥有值可以交给另一个线程）和 `Sync`（`&T` 可以被多个线程同时使用）。v1 不允许手写这两种能力。

| 操作 | 条件 |
| --- | --- |
| 把拥有值 `T` 交给另一个线程（`spawn` 的移动参数、channel 发送） | `T: Send` |
| 多个线程共享只读借用 `&T` | `T: Sync` |
| `Arc[T]` 跨线程 | `T: Send` 且 `T: Sync` |
| `Arc[Mutex[T]]` 跨线程 | `T: Send` |
| `Rc[T]` | 永远不能跨线程 |

- **P1 `Arc[Mutex[Rc[T]]]` 必须拒绝。** 锁只保护它里面那一份值，保护不了 `Rc` 在别处的别名；这个类型也不能作为任何诊断的自动修复结果。
- **P2 接口值的能力。** `Box[Named]` 擦除了具体类型，默认既不是 `Send` 也不是 `Sync`；需要跨线程时写 `Box[Named + Send]`，装箱时检查具体类型。`+ Send` 只代表能转交给另一个线程，不代表能被多个线程共享，共享还需要 `+ Sync`。
- **P3 线程借用保守持续到 scope 结束。** `scope` 里 `spawn` 借用的数据，借用一直持续到 `scope` 等待所有线程结束，而不是到线程句柄最后一次被使用。`return`、`try`、`break` 提前离开 `scope` 时，先等待所有线程结束，再释放数据；丢弃句柄不解除借用；线程不能借用比 `scope` 更短命的局部变量；v1 的线程返回值必须为 `Send` 且不携带借用。`join()` 消耗句柄、取得返回值，但 v1 不据此提前缩短借用：仍保守保留到所属 scope 结束。丢弃句柄只丢弃取得返回值的权利；scope 仍等待线程。`Join` 不得逃出所属 scope。
- **P4 锁守卫。** `with g = m.lock() { }` 里从 `g` 借出的引用只能在块内使用：离开块后，即使 `m` 还活着，访问也不再受锁保护。借用系统同时跟踪两种存活：数据的存活，以及访问许可（锁守卫）的存活。
- **P5 channel 契约（v1）。** 元素类型必须是 `Send` 且不携带借用；`send` 移动值；关闭后 `send` 返回 `err(.Closed(value))`，把值还给调用者；关闭后 `recv` 先排空缓冲区，再返回 `none`。
- **P6 内建类型的契约。** 由编译器规定，用户不能声明：通过 `Rc[T]`、`Arc[T]` 只能得到共享的只读访问，把句柄放进 `var` 也不会变成排他可写；`Mutex[T]` 只通过锁守卫提供可变访问；锁守卫不是 `Send`，不能移到别的线程，必须在取得锁的线程析构。普通用户类型的 `Send`、`Sync` 再按字段结构推导。

- **P7 临时切片不是临时数据。** `spawn sum(v[a..b])` 合法，前提是 `v` 在当前 scope 之前已存在并满足共享条件；切片描述符会复制到启动参数存储，底层数据仍借用 `v`。`spawn sum(makeVec()[0..2])` 不合法，因为拥有数据的临时 `Vec` 在语句末销毁。在 scope 内创建的短命拥有者，即使马上 `join`，v1 仍拒绝；可以先创建拥有者，再进入一个更内层的 scope。
- **P8 并发 API。** 构造、`lock`、`tryLock`、channel、`Join` 的签名与错误路径以《标准库契约》为准。`Guard` 既不是 Send 也不是 Sync；同线程递归 `lock` panic，`tryLock` 在任何竞争（含同线程）时返回 none。关闭 channel 幂等，唤醒阻塞的发送和接收，发送失败必须返还原值。
